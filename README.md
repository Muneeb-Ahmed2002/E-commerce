# e_commerce_mini_app

A simple E-Commerce Application using Flutter

## Getting Started
This project is developed in flutter and tested on Android Mobile Device at current time Being.

This is a small E-Commerce based app with separate UI and Business logic as much as possible for a clear code structure and for clean coding practices.


This project uses a very clean architecture with Provider used for StateManagement// Although provider is a good solution for state management but it only allows for state management in the same user session and no more than that.
It uses Multiple Providers each for a different purpose and can separate mixing up different providers. Which obviously cannot be a good idea.
